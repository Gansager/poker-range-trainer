# Poker Range Trainer

**🎮 Демо: https://gansager.github.io/poker-range-trainer/**

Веб-приложение для тренировки префлоп-диапазонов в покере. Выбираешь действия для рук
в матрице 13×13, нажимаешь **Check** — приложение сравнивает ответ с эталонным диапазоном
и подсвечивает несоответствия.

На базе чартов FunFarm: Открытие (RFI), VPIP vs 1 raiser, BB defense, Blind vs Blind, ISO vs Fish.

## Возможности

- Матрица 13×13 (169 рук) с раскраской мышью и **свайпом на тач-экранах**.
- Смешанные стратегии с частотами (3бет 35% / колл 65%) — диагональные полосы как на чартах.
- Два режима проверки: **«Действие»** (любое действие из эталона) и **«Частоты»** (точные доли с допуском ±%).
- Встроенный **редактор** диапазонов: правка кистью + слайдер частоты, заметки, импорт/экспорт JSON.
- Данные хранятся в `localStorage`; работает офлайн.
- Адаптивная вёрстка под десктоп и телефон.

## Стек

React 18 + TypeScript + Vite, zustand (+persist), Vitest.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка
npm run test     # unit-тесты
```

## Статус данных

Стартовые диапазоны в `src/data/*Ranges.ts` — **черновик** (теория + структура чартов FunFarm),
требует сверки и правки в редакторе. См. [REQUIREMENTS.md](./REQUIREMENTS.md).
